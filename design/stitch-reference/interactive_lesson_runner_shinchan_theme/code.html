Mission: Loop-de-Loop

Objectives

Initialize System
Write the For Loop
Defeat the Boss

Briefing

Action Kamen needs to punch 5 times to break the barrier! We don't have time to write 'punch' five times. Use a FOR LOOP to automate his attacks! 

function breakBarrier() {
  for (let i = 0; i < 5; i++) {
    actionKamen.punch();
  }
}
